# Night-shift session

Fokus (opsional, default: seluruh sesi ini): $ARGUMENTS

## Workflow

1. Scan transkrip sesi ini → rank 1 improvisasi bernilai tertinggi → implement
   (diff terkecil) → verifikasi → lapor 1-2 baris → ulangi.
2. Budget default 10 iterasi, berhenti lebih awal kalau habis bahan.
3. Berhenti = tulis analisa pengembangan (prioritas) ATAU `blocked: ...`.
4. Batas keras: tanpa malware/exploit/phishing/merugikan, tanpa push,
   tanpa `.env`/secret/destruktif — "improvisasi" bukan alasan melanggar.
